## 🚀 Opções de Hospedagem Gratuita:

### 1. NETLIFY DROP (MAIS FÁCIL)
1. Acesse: https://app.netlify.com/drop
2. Arraste esta pasta completa (`landing-deploy`)
3. Receba URL instantâneo: `https://random-name.netlify.app`

### 2. VERCEL
1. Acesse: https://vercel.com
2. Clique "New Project"
3. Upload desta pasta
4. Deploy automático com SSL

### 3. GITHUB PAGES
1. Crie repositório público no GitHub
2. Upload dos 3 arquivos
3. Settings → Pages → Source: Deploy from branch
4. URL: `https://seu-usuario.github.io/repositorio`
